# JavaScript Fundamentals Practice

A collection of beginner-friendly JavaScript problems I solved while learning the fundamentals of web development.

These exercises helped me practice writing functions, handling input validation, working with strings, arrays, objects, loops, conditions, and basic problem-solving logic.

## Problems Covered

* Calculate a discounted price with input validation
* Validate an OTP format
* Calculate an exam score from correct and incorrect answers
* Compare votes using arrays and loops
* Analyze text to find the longest word and count characters

## Concepts Practiced

* JavaScript Functions
* Conditional Statements
* Input Validation
* Arrays
* Objects
* Loops
* Strings and String Methods
* Basic Mathematical Operations
* Logical Problem Solving

## Technologies Used

* JavaScript (ES6+)

## Purpose

This repository represents my JavaScript practice while building a strong foundation for frontend and web development.
